Importar edital de outro concurso

Importe um arquivo estruturado .txt ou .json. O sistema cria disciplinas e assuntos próprios sem modificar a CGU e o TCE-GO.

Não extrai diretamente um PDF nem identifica automaticamente matérias em comum. Para importação confiável, prepare um TXT com cabeçalhos de disciplinas ou um JSON estruturado.

Formato do arquivo TXT

CONCURSO: Meu próximo concurso\nDATA: 2027-06-15\nDISCIPLINA: Língua Portuguesa\n- Interpretação de textos\n- Concordância verbal\nDISCIPLINA: Banco de Dados\n- JOIN, GROUP BY, HAVING\n- Transações e propriedades ACID

Também aceita JSON

{"nome":"Meu concurso",\n "data":"2027-06-15",\n "disciplinas":[\n   {"nome":"Banco de Dados",\n    "topicos":["SQL", "Normalização"]}\n ]}

Diagnóstico de salvamento

Verificando o armazenamento…

O site salva no armazenamento local deste endereço, não na conta GitHub. Não abra o HTML em uma prévia incorporada, navegador anônimo ou modo que bloqueie dados de sites. Prefira o endereço publicado no GitHub Pages. Não use o arquivo de backup JSON como parte do repositório público.

Backup deste perfil

O backup inclui progressos, anotações, históricos, PDFs vinculados e concursos importados. Guarde-o em local seguro: ele contém informações pessoais em texto legível.

GitHub Pages disponibiliza o site, mas não armazena os dados de cada usuário. O progresso fica neste navegador. Para acessar os mesmos dados em outro aparelho, exporte e importe o backup.

Privacidade e perfis

Perfis e alterações são salvos no localStorage do navegador, com verificação de gravação. Anotações de tópicos são salvas automaticamente enquanto você digita. Não são contas com login, senha ou criptografia. Qualquer pessoa com acesso a este mesmo navegador poderá abrir os perfis locais. Não grave senhas, documentos sigilosos ou informações de terceiros.

Apagar dados do site ou usar aba anônima pode apagar seu progresso. Faça backups periódicos. Para sincronização real, será necessário acrescentar autenticação e armazenamento em nuvem.
